## 📋 Sobre o Projeto

O **Drogaria Higashi** é um sistema completo desenvolvido para a gestão e organização de uma farmácia/drogaria. A aplicação integra um front-end web dinâmico com um servidor em Java conectado a um banco de dados relacional MySQL, permitindo o controle eficiente de estoque, cadastro de medicamentos e gerenciamento de vendas.

## 🚀 Funcionalidades

- **Catálogo de Produtos:** Exibição de medicamentos, produtos de higiene e cosméticos.
- **Busca e Filtros:** Pesquisa rápida de itens cadastrados no banco de dados.
- **Gestão de Estoque:** Controle de entrada, saída e atualização de produtos via backend em Java.
- **Persistência de Dados:** Integração completa com o banco de dados MySQL.
